# Обновления

Новые подготовленные версии могут публиковаться в разделе **Releases**.
Каждый выпуск содержит номер версии, краткое описание изменений и
соответствующие вложения. Наличие страницы GitHub не меняет способ
обновления уже установленного клиента автоматически.

## Начиная с 1.3.1

Приложение сначала проверяет обновления и загружает файл через официальный
сайт WxP. При ошибке загрузки может использоваться резерв того же выпуска
в GitHub Releases. Если весь сайт недоступен, адрес резервной информации
о версии уже известен приложению — получать его с сайта в этот момент не нужно.

Для этой схемы у конкретного выпуска должны быть опубликованы готовый EXE,
соответствующий `update.json` и корректное объявление на сервере WxP.
Наличие файлов в репозитории документации само по себе не включает обновление.

Перед установкой проверяются размер, SHA-256, версия и подпись издателя EXE.
При несовпадении установка отменяется. Подписка и аккаунт обслуживаются
инфраструктурой WxP; резерв загрузки не заменяет работу сервера аккаунтов.

В клиентах 1.3.0 и ниже адрес резервных сведений не встроен. Если официальный
сайт недоступен, переход на новую версию выполняется вручную через Releases.

## Ручная установка

Завершите приложение через **«Выход»** в трее, сохраните свой код доступа
в безопасном месте и замените файл программы на проверенный файл выпуска.
Не удаляйте пользовательский каталог настроек ради обычного обновления.

Если обновление не установилось, в сообщении об ошибке укажите старую и новую
версии, шаги и точный текст ошибки. Удалите из снимков и журнала коды,
личные адреса и сведения аккаунта.
