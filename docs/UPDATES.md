# Обновления

Новые подготовленные версии могут публиковаться в разделе **Releases**.
Каждый выпуск содержит номер версии, краткое описание изменений и
соответствующие вложения. Наличие страницы GitHub не меняет способ
обновления уже установленного клиента автоматически.

## Текущее состояние

Клиент 1.3.0 получает сведения об обновлении от инфраструктуры WxP.
Автоматический резервный источник GitHub Releases пока не подключён.
До его подключения файлы из Releases можно использовать для ручной установки,
если конкретный бинарный выпуск опубликован и проверен.

## Планируемый резерв

Основной источник файла остаётся у WxP. GitHub Releases планируется как
дополнительный источник того же выпуска на случай недоступности основного.
Номер версии и адреса загрузки будут управляться через инфраструктуру WxP;
подписка и аккаунт продолжают обслуживаться сервером WxP.

Переход к этому механизму требует отдельного изменения клиента. Эта страница
не означает, что GitHub уже используется текущим автообновлением.

## Ручная установка

Завершите приложение через **«Выход»** в трее, сохраните свой код доступа
в безопасном месте и замените файл программы на проверенный файл выпуска.
Не удаляйте пользовательский каталог настроек ради обычного обновления.

Если обновление не установилось, в сообщении об ошибке укажите старую и новую
версии, шаги и точный текст ошибки. Удалите из снимков и журнала коды,
личные адреса и сведения аккаунта.
