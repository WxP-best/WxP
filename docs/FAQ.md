# Вопросы и ответы

## Где скачать приложение?

В разделе **Releases**, во вложениях конкретного выпуска. Выбирайте `WxP.exe`;
автоматический архив Source code содержит только содержимое этой страницы.
[Порядок загрузки](DOWNLOADS.md).

## Почему репозиторий публичный, а исходников нет?

Код клиента WxP остаётся закрытым. Публичная страница содержит документацию,
историю выпусков, уведомления о сторонних компонентах и обратную связь.

## Нужно ли оплачивать повторно после обновления?

Обновление программы не является новой покупкой подписки. Используйте свой
существующий аккаунт. Срок доступа и действующие тарифы видны в приложении.

## Обязателен ли Telegram для регистрации?

Нет. В приложении предусмотрены получение доступа после оплаты и вход по
коду. Telegram можно привязать к аккаунту отдельно.

## Почему после нажатия крестика процесс остаётся?

Крестик сворачивает окно в системный трей. Для полного завершения используйте
пункт **«Выход»** в меню значка WxP.

## Весь компьютер автоматически использует выбранное подключение?

Выборочные правила относятся к выбранным сервисам и приложениям. Отдельный
режим расширяет отбор соединений с предусмотренными исключениями.
Подробнее: [режимы и ограничения](OVERVIEW.md).

## Почему Windows предупреждает о подписи?

Существующий выпуск использует самоподписанный сертификат. Он не становится
доверенным автоматически на чужом компьютере. Фактический статус каждого
выпуска указывается в его описании. [Подробнее о подписи](../CODE_SIGNING.md).

## Как сообщить об ошибке?

Откройте **Issues → New issue** и заполните форму. Опишите проблему без кодов
доступа и платёжных данных. Вопросы оплаты передавайте в официальный канал
поддержки сервиса. Возможные уязвимости отправляйте согласно [SECURITY.md](../SECURITY.md).
