## Первый запуск

1. Откройте скачанный `WxP.exe`. Подтвердите запрос прав администратора.
2. Нажмите **«У меня уже есть код»** и введите личный код доступа.
   Если доступа ещё нет, выберите **«Получить доступ»**.
3. Включите нужные сервисы, подключитесь и дождитесь проверки.

Для начала работы с WxP не нужно вручную собирать файл подключения.
Если сеть или конкретный сервис не открывается, напишите в
[Q&A](https://github.com/WxP-best/WxP/discussions/categories/q-a)
или [поддержку](https://t.me/blogWxP?direct).

## Что потребуется

- Windows x64 и интернет.
- Microsoft Edge WebView2 для интерфейса.
- Права администратора для сетевых компонентов.
- Действительный код доступа для функций обслуживаемого сервиса.

Приложение поставляется одним EXE. Входящие в него сетевые компоненты
могут распаковываться в каталог данных Windows во время работы.

## Если Windows показывает предупреждение

Выпуск 1.3.1 подписан самоподписанным сертификатом. Он не получает
автоматическое доверие Windows на чужом компьютере. Подробнее —
в [описании подписи](../CODE_SIGNING.md).

Скачивайте программу с официальной страницы и сверяйте SHA-256 с файлом
`SHA256SUMS` того же выпуска. Команда PowerShell в папке загрузки:

```powershell
Get-FileHash -Algorithm SHA256 -LiteralPath .\WxP.exe
```

## Где именно находится приложение на GitHub

Если открыли страницу выпуска, раскройте **Assets** и выберите **`WxP.exe`**.
Архивы **Source code (zip)** и **Source code (tar.gz)** содержат документацию
этого репозитория. Для запуска программы они не нужны.

## Как закрыть и обновить

Крестик сворачивает WxP в трей. Для полного завершения нажмите правой кнопкой
на значок WxP рядом с часами и выберите **«Выход»**.

Обновляйтесь через приложение или заменяйте EXE после полного выхода.
Сохраните свой код в безопасном месте. Обновление не является новой подпиской.
