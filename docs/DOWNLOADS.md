# Загрузка и первый запуск

Сайт сервиса и инструкции: [wxp2026.xyz](https://wxp2026.xyz/).

1. Откройте раздел **Releases** справа на главной странице репозитория.
2. Выберите актуальный стабильный выпуск и раскройте **Assets**.
3. Скачайте `WxP.exe`. Ознакомьтесь с описанием версии и статусом подписи.
4. Если опубликован `SHA256SUMS`, сравните контрольную сумму скачанного файла.
5. Запустите клиент, введите свой код доступа и выберите сервисы.

Если выпусков или вложения `WxP.exe` ещё нет, загрузка приложения через этот
репозиторий пока не опубликована. Обновления страницы документации сами по
себе не означают выпуск новой программы.

Кнопки **Source code (zip)** и **Source code (tar.gz)** GitHub формирует
автоматически из содержимого репозитория. Для этой страницы это архив
документации, а не приложение и не закрытые исходники WxP.

## Требования

- Windows x64.
- Microsoft Edge WebView2 для интерфейса.
- Права администратора для сетевых компонентов.
- Интернет и действительный код доступа для функций обслуживаемого сервиса.

Приложение распространяется одним EXE; необходимые сетевые компоненты
входят в состав подготовленного файла. Во время работы они могут
распаковываться в каталог данных приложения.

## Проверка файла

В PowerShell, в каталоге загрузки:

```powershell
Get-FileHash -Algorithm SHA256 -LiteralPath .\WxP.exe
```

Сравните полное значение с контрольной суммой того же выпуска.
Сведения о цифровой подписи: [Code signing policy](../CODE_SIGNING.md).
