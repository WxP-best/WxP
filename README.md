<p align="center">Ваши сервисы. Одно подключение.</p>

WxP — сетевой клиент для Windows с понятным выбором сервисов и приложений.
Войдите по своему коду, выберите нужное и управляйте подключением из одного окна.

**Windows x64 · версия 1.3.1 · закрытый код клиента · доступ по подписке**

[Сайт WxP](https://wxp2026.xyz/) · [Загрузка и запуск](docs/DOWNLOADS.md) · [Подписка](docs/SUBSCRIPTIONS.md) ·
[Обновления](docs/UPDATES.md) · [Вопросы и помощь](docs/FAQ.md)

Для интерфейса используется
Microsoft Edge WebView2. Сетевым компонентам нужны права администратора.

## Возможности

- Выбор сервисов по плиткам: мессенджеры, видео, социальные сети, стриминг и ИИ.
- Отдельные правила для выбранных EXE-приложений.
- Передача выбранных соединений через удалённый узел с изменением внешнего IP.
- Отдельный режим обработки соединений без изменения внешнего IP.
- Подбор подключения и проверка доступности включённых сервисов.
- Режим совместимости для совместной работы с другими сетевыми программами.
- Интеграция подключения Telegram Desktop через локальный прокси.
- Тест скорости активного подключения, журнал, работа в системном трее и обновления.

Выборочная маршрутизация распространяется на выбранные правилами соединения.
Она не означает полную анонимность или автоматическую защиту всего компьютера.
Особенности браузеров и совместимости описаны в [обзоре](docs/OVERVIEW.md).

## Начало работы

1. Если опубликован готовый выпуск, откройте раздел **Releases** этого репозитория.
2. Скачайте файл приложения и сверьте контрольную сумму из описания выпуска.
3. Запустите приложение, введите свой код доступа и выберите нужные сервисы.
4. Подключитесь и дождитесь результата проверки.

Доступ к удалённой инфраструктуре предоставляется по подписке. Условия и срок
доступа отображаются в приложении. Сторонние проекты, перечисленные ниже,
распространяются на собственных условиях и не являются платными продуктами WxP.

Крестик окна сворачивает приложение в трей. Для полного завершения используйте
**«Выход»** в меню значка трея.
