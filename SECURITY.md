# Сообщения о безопасности

Если проблема может раскрыть код доступа, позволить обойти авторизацию,
запустить посторонний код или получить доступ к чужим данным, не публикуйте
подробности в открытом Issue.

Используйте **Security → Report a vulnerability**, если владелец репозитория
включил приватные отчёты. Если эта функция недоступна, используйте официальный
контакт поддержки проекта. Не отправляйте секреты в публичные обсуждения.

Укажите версию, условия воспроизведения, ожидаемый результат и возможное
влияние. Удалите коды доступа, ссылки подключения, пароли, платёжные ссылки,
личные адреса, имена пользователей и внутренние домены из вложений.

Обычные ошибки работы можно описывать через Issues без приватных данных.
Не требуется отключать защиту Windows или устанавливать неизвестные
сертификаты ради отправки отчёта.
