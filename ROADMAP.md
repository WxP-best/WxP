# 🧭 Куда развивается WxP

Цель — удобное приложение для повседневных сервисов: понятный запуск,
предсказуемое подключение и управление из одного окна.

Здесь разделены выпущенные возможности и направления дальнейшей работы.
Планы могут меняться по результатам обратной связи; даты пока не назначены.

## ✅ Уже в приложении

| Возможность | Что даёт пользователю |
| --- | --- |
| Выбор сервисов и своих Windows-приложений | Настройку подключения под свои задачи |
| Автоподбор и проверка сервисов | Меньше ручного перебора подключений |
| Подключение Telegram Desktop | Управление Telegram вместе с остальными сервисами |
| Вход по коду без обязательного Telegram | Возможность начать с самого приложения |
| Режим совместимости | Дополнительный вариант при конфликтах сетевых программ |
| Обновления с резервом на GitHub | Второй источник файла при недоступности основного |

[История выпусков](CHANGELOG.md).

## 🔧 Следующий фокус

Это направления развития, а не список уже реализованных функций.

| Направление | Какого результата хотим |
| --- | --- |
| Надёжность на разных компьютерах | Больше проверенных сочетаний Windows, сетей и других сетевых программ |
| Понятная диагностика | Объяснение причины ошибки и короткий следующий шаг |
| Первый запуск | Меньше вопросов о входе, выборе режима и начале подключения |
| Автоподбор | Более понятный результат проверки и выбора подключения |
| Инструкции | Ответы на частые вопросы рядом с нужным действием |

## Как читать статусы

- **Уже в приложении** — возможность есть в опубликованной версии.
- **Следующий фокус** — приоритетное направление без обещанной даты.
- **Обсуждаем** — идея, по которой ещё нужно принять решение.

Совместимость и скорость зависят от конкретной сети и компьютера.
Универсальная работоспособность со всеми программами не заявляется.
