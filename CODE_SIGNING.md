# Code signing policy

WxP 1.3.0 подготовлен с самоподписанным сертификатом. Это не публично доверенный
сертификат удостоверяющего центра и не подпись SignPath Foundation.
Windows может не доверять такой цепочке и показывать предупреждение.

При выпуске проверяются целостность файла, версия и подпись. Контрольную сумму
нужно брать из описания именно того выпуска, который вы скачиваете.

Проверка в PowerShell:

```powershell
Get-FileHash -Algorithm SHA256 -LiteralPath .\WxP.exe
Get-AuthenticodeSignature -LiteralPath .\WxP.exe | Format-List Status,StatusMessage,SignerCertificate
```

Контрольная сумма подтверждает совпадение файла с опубликованным значением,
но сама по себе не удостоверяет издателя. Подпись также не гарантирует
отсутствие ошибок, срабатываний антивируса или предупреждений SmartScreen.

Публичная документация на GitHub сама по себе не даёт сертификат.
Сотрудничество с поставщиком доверенной подписи пока не заявлено.
Если способ подписи изменится, политика и описание соответствующего выпуска
будут обновлены вместе.

Подпись приложения не заменяет исходные подписи сторонних драйверов.
